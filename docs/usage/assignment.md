# Cell assignment

!!! warning "Under construction"
    This page is still under construction.

Cell assignment converts cell alignment scores to cell assignments (pairs of matched
cells), using maximum score assignment or linear sum assignment, optionally combining
forward and reverse alignment scores (`--direction`).
